# Digital Gift Card and Loyalty Point Exchange

## Project Overview

This project models a digital gift-card and loyalty-point exchange
system using Jira. The system allows account holders to view and
validate loyalty points, convert merchant loyalty points into universal
exchange credits, redeem digital gift cards, and protect voucher
redemptions against duplicate or unauthorized use.

## Epics and User Stories

### 1. Loyalty Point Management

**Goal:** Enable account holders to view and validate their loyalty
points before converting them into universal exchange credits.

  User story                  Story points
  ------------------------- --------------
  View Loyalty Balance                   2
  Validate Loyalty Points                3

### 2. Loyalty Point Conversion

**Goal:** Enable account holders to convert valid merchant loyalty
points into universal exchange credits using the applicable dynamic
conversion rate.

  User story                 Story points
  ------------------------ --------------
  Check Exchange Rate                   2
  Convert Loyalty Points                5

### 3. Gift Card Redemption

**Goal:** Enable account holders to use universal exchange credits to
redeem digital gift cards and receive digital voucher codes.

  User story                   Story points
  -------------------------- --------------
  Redeem Gift Card                        5
  Generate Digital Voucher                3

### 4. Voucher Security and Fraud Prevention

**Goal:** Protect digital gift-card redemptions by locking vouchers and
preventing duplicate or unauthorized voucher use.

  User story                       Story points
  ------------------------------ --------------
  Lock Voucher                                3
  Prevent Duplicate Redemption                5
